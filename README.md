# Joh's Stack — Christian Johanes Portfolio

A clean, recruiter-focused personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or run a local static server. No build step is required.

## Deploy to GitHub Pages
1. Commit the updated files to the repository branch configured for GitHub Pages.
2. Push to GitHub.
3. Open **Settings → Pages** and confirm the deployment source points to the correct branch and root folder.

## Main sections
- Introduction and professional positioning
- About
- Experience and learning
- Featured projects: FinDirect and CutiApp
- Technical skills
- Contact and social links

## Files
- `index.html` — main portfolio page
- `style.css` — responsive clean-minimalist styling
- `public/js/main.js` — mobile navigation and footer year
- `foto_profil/` — profile photographs
- `Joh's Stack.jpg` — site favicon
